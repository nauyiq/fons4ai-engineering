# 小变更

适用于范围明确、可逆、局部且无重大业务、公共契约、数据或安全影响的工作，包括简单行为调整。先核实代码/文档基线，简述当前与期望差异、影响范围及验收，再按已有授权执行。是否需要正式规格取决于复杂度与风险，不仅取决于有无行为变化。

行为变化（包括配置改变运行行为）进入 [实现](../../fons4ai-sdd-implement/SKILL.md)，以 TDD 和适当行为验证完成；不要求先补三件套。无行为修改使用现有聚焦检查，文档检查链接、无行为重构复用回归。

无需新建 CR、三件套或报告。已有过程记录需要同步时只改受影响内容。若中途发现重大风险、范围扩大或需重新决定关键业务规则，转 [规格变更](spec-change.md)，保留已完成的无争议工作；不因已经预期的简单行为变化重复升级流程。
