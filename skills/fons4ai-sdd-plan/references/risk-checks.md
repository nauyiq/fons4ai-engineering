# 风险提示：识别问题，不扩写模板

在规划就绪、实现前出现新事实、完成验收三个节点检查适用项；把影响决定的内容写到已有文档中，不另建风险表。

| 触发 | 需要查明 |
| --- | --- |
| 业务规则/状态变化 | 前置条件、不变量、异常路径、幂等、并发与补偿 |
| 数据与迁移 | 精度/null/时区等语义、既有数据兼容、迁移顺序、恢复方式 |
| 公共接口/外部系统 | 契约兼容、失败与重试、超时、依赖版本与运行配置 |
| 权限/敏感数据 | 信任边界、身份与租户隔离、日志与信息暴露 |
| UI 交互 | 加载、空、失败、权限及重复操作状态 |
| 资源/性能/部署 | 生命周期、容量、取消与清理、环境差异、可观测性 |

测试与验证选择能证明实际风险的层次；不要只测正常路径或用全 Mock 证明外部行为。无关项无需写“不适用”。发现新的重大风险时调整已有计划，不静默放宽验收。
